Questions people ask most

D365 glossary
Which copy of a guide should I trust?

The one on this site. Each guide shows its version and last review date on the first page. Downloaded or printed copies are not updated when the process changes.

The guide shows a menu I can't see in D365

Your security role decides which menus appear. Check the "Who this is for" box at the top of the guide, then raise an access request if your role needs it.

My template import failed. What should I check?

Open the import job in Data management and review the staging errors row by row. Most failures come from a value the column guide doesn't allow. If the error remains, raise a D365 support request and attach the file.

Where can I practice without touching live data?

Use the D365 training environment. Nothing you do there reaches live data, and every learning path links to it.

How do I report an error or ask for a new guide?

Use the suggestion form on this page. The training team logs every request against the guide's process owner and replies within five business days.
