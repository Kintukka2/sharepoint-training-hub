# Fonts

DM Sans (Regular 400, Medium 500, Bold 700) and DM Mono (Regular 400, Medium 500), the WiseTech Global brand typefaces, taken from the WiseTech Global Design System and converted to WOFF2 with a Latin subset (U+0000–00FF, general punctuation, arrows, € and ™).

Both families are licensed under the SIL Open Font License 1.1. `tools/build.py` embeds these files into the SharePoint page as base64 `@font-face` rules.
